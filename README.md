# 走過 Zouguo

填一填去過哪裡，馬上變成一顆可以轉的地球。

- **Web**：`docs/`，純前端，沒有後端也沒有帳號
- **iOS**：`ios/`，SwiftUI 原生，同一套地球引擎的 Swift 版
- 兩邊共用同一份 JSON 格式，可以互相匯入、互丟分享連結

## 為什麼做這個

市面上填國家看地圖的工具（Mark O'Travel、been、Visited）都停在「一張平面地圖 + 一份清單」。
這個版本的差別在輸出：**一顆真的可以轉、可以縮放、去過的國家整片點亮的地球**，
而且可以直接存成一張適合發社群的圖片。

## Web 版

```bash
cd docs && python3 -m http.server 8777
# 開 http://127.0.0.1:8777
```

沒有建置步驟，沒有相依套件。部署就是把 `docs/` 整個丟上任何靜態主機（見 DEPLOY.md）。

**功能**
- 點地球上的國家直接標記（螢幕座標反投影回經緯度，再做多邊形內判定）
- 搜尋國家（中英文都可）或 13,674 個城市
- 每個國家可以加年份、加城市；填了年份就會出現時間軸，可以只看某一年
- 存成圖片（1080×1350，適合 IG）
- 分享連結：狀態壓成 base64 放在 URL hash，對方打開就看得到
- 匯出／匯入備份 JSON
- 深淺色都有

**資料存哪**：`localStorage`。沒有伺服器、沒有追蹤、不會主動上傳。
但要誠實說清楚邊界：分享連結會把內容編進網址（base64 是編碼，不是加密）；
`localStorage` 以網域為單位，如果部署在 `github.io` 這種共用網域下，同網域的其他頁面讀得到。
在意的話請用獨立子網域部署。

### 冒煙測試

```
http://127.0.0.1:8777/index.html?selftest=1
```

會跑 21 項檢查（資料完整性、分享連結往返、反投影點名國家、PNG 輸出），
結果印在畫面下方，標題列會顯示 `ALL PASS` 或 `N FAILED`。
改完 `globe.js` 或資料檔請先跑這個。

## iOS 版

```bash
cd ios && xcodegen generate && open Zouguo.xcodeproj
```

需要 [xcodegen](https://github.com/yonaskolb/XcodeGen)（`brew install xcodegen`）。
專案檔是產生出來的，不進版控。

**已驗證**：Xcode 26.2 / iOS 17+ 目標，模擬器實機跑過，地球、著色、統計、時間軸都正常。

**功能**：地球（拖曳旋轉、捏合縮放、點國家標記）、搜尋、清單、年份、城市、分享連結、備份匯入匯出。

## 兩邊怎麼連動

沒有帳號系統，用**分享連結**當橋：

1. iOS：分享與備份 → 複製連結 → 得到 `https://…/#<base64>`
2. Web：打開那個連結，就是同一顆地球
3. 反過來也可以：Web 的連結貼進 iOS 的「從剪貼簿匯入」

備份 JSON 的欄位名兩邊完全一致（`{v, c: {ISO: {y: [年份], t: [城市]}}}`），所以檔案也能直接互丟。

## 資料來源

- 國界：[Natural Earth](https://www.naturalearthdata.com/) 110m（公有領域），座標精度降到小數點 1 位以縮小檔案
- 城市：[GeoNames](https://www.geonames.org/) cities1000（CC BY 4.0），篩人口 4 萬以上＋各國首都＋知名旅遊小鎮
- 國名中文：手工對照表（`scripts/zh_names.py`），台灣用語

重建資料：

```bash
python3 scripts/build_data.py
```

## 已知邊界

- 摩納哥、梵蒂岡、新加坡等 14 個國家在 110m 國界資料裡沒有多邊形，用一個點代表。
  它們在地球上點不到（點下去會命中包住它的鄰國），請用搜尋加入
- 法屬圭亞那、夏威夷這類遠離本土的海外領土會單獨拆出來，不隨本土一起點亮
- **國家跨到地球邊緣時，填色會被弦切掉一小塊**。正解是沿球緣做球面裁切
  （D3 的 `clipCircle` 那一套）；試過用單一 `arc()` 補弧，實測反而讓填色更小
  （俄羅斯：直線 3701 px、短弧 3390、長弧 2739），所以維持現狀等日後重做
- 世界進度的分母是 **199**：195 個聯合國成員（193 會員＋梵蒂岡＋巴勒斯坦）
  再加台灣、香港、澳門、科索沃。分子只算同一個集合裡的項目，所以填滿真的會到 100%。
  南極洲、格陵蘭等純領土仍可標記，但不計入分母。
